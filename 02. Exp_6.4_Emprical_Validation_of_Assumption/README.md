# Sec 6.3 — Empirical Validation of the Local-Error Assumption at Coverage Failures

Validates the core theoretical assumption motivating LACI: at ACI coverage-failure points,
the instantaneous left-centered local error LE⁽ᴸ⁾ᵢ systematically exceeds the recency-weighted
average local error LEᵢ in expectation. This condition — E[LE⁽ᴸ⁾ᵢ − LEᵢ | errᵢ = 1] > 0 —
is the empirical foundation for LACI's severity-weighted update scheme.

## Files

- `Exp_6.3.ipynb` — main experiment notebook; runs ACI (γ = 0.001) with LSTM on all 9 datasets,
  identifies coverage-failure points, and computes LE⁽ᴸ⁾ᵢ vs. LEᵢ at each failure
- `Final_Results.txt` — aggregated numerical results matching Table 3 of the paper
- `outputs/` — per-dataset summary statistics and any saved figures generated by the notebook

## Run

```bash
jupyter notebook Exp_6.3.ipynb
```

Results are written to `Final_Results.txt` and `outputs/` at the end of the notebook run.

## Experimental Setup

| Parameter | Value |
|---|---|
| Architecture | LSTM (hidden dim: 64, layers: 1) |
| Initial training window (T_init) | 5,000 samples |
| Fine-tuning cadence | Every 6 hours (online) |
| Sequence length | 48 |
| Target coverage (1 − α) | 0.90 |
| Local evaluation window (w) | 24 hours |
| ACI step size (γ) | 0.001 |
| Decay factor (M) | 0.95 |
| Random seed | 42 |

## What is being validated

For each dataset, every ACI coverage-failure point (errᵢ = 1) is identified. At each such point,
two local error quantities are computed:

- **LE⁽ᴸ⁾ᵢ** — left-centered local coverage error over the past w = 24 steps
- **LEᵢ** — recency-weighted average of past local errors (decay M = 0.95)

The assumption holds whenever LE⁽ᴸ⁾ᵢ > LEᵢ at a coverage-failure point. The notebook reports
the percentage of failure points satisfying this condition and the mean difference
Δ = Mean(LE⁽ᴸ⁾ᵢ) − Mean(LEᵢ) per dataset.

## Results (Table 3 from paper)

Approximately **63.57%** of local coverage errors across all datasets are attributed to abrupt
distributional shifts, characterised by LE⁽ᴸ⁾ᵢ > LEᵢ at coverage-failure points. The condition
holds in the majority of failure cases for every dataset considered, and Δ remains strictly
positive throughout.
